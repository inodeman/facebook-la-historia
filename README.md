# Facebook: La Historia

Documental en español, formato YouTube 16:9, sobre la historia de Facebook. Reconstrucción 3D, narración continua y capítulos. De InodeAI.

## Verlo

```bash
npm install
npm run dev
```

Abre la portada y pulsa **Reproducir**. Dura alrededor de quince minutos. La barra, los capítulos y las teclas espacio y flechas controlan la narración.

## Nota

Las imágenes son reconstrucciones. No son fotos de archivo ni retratos de personas reales. Los datos (fechas, compras, usuarios, la multa de 2019, la cifra de Meta en 2026) siguen el registro público.

Canal: [InodeAI en YouTube](https://www.youtube.com/user/inodeEntertainment)
